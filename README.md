# Mega Rockets — 0.4.0 Alpha

Экспериментальный мод для Minecraft Java Edition 1.21.1 + Fabric. Titan-1 — 64 блока высотой, корпус 10 блоков в диаметре, габариты до 14 блоков. Готовая модель на Java с семью детализированными двигателями, 48 сегментами окружности, панелями и рёбрами.

## Сборка
GitHub Actions автоматически запускает Gradle 8.8 и Java 21 при обновлении main. После успешной сборки скачайте архив в Actions → нужный запуск → Artifacts и извлеките JAR. Для запуска необходимы Fabric Loader и Fabric API для 1.21.1.

Локально: JDK 21, Gradle 8.8, команды gradle build или gradle runClient.

## Испытание
Используйте новый плоский мир в творческом режиме с читами. 
- /rocket spawn — ракета в 15 блоках впереди. Освободите область 14×64×14.
- /rocket launch — посадка, обратный отсчёт, вертикальный старт.
- /rocket return — возвращение к точке появления.
- /kill @e[type=megarockets:titan_1] — удаление ракеты.

Ракета физически поднимается в обычном мире до Y=10000 (координата основания, не виртуальный счётчик), с разгоном до 120 блоков/с и телеметрией. На Y=10000 предусмотрен переход в измерение megarockets:orbit с продолжением полёта до Луны. Не сходите с ракеты во время полёта. Для обзора всей ракеты нажмите F5: при посадке камера третьего лица отдаляется до 96 блоков (с учётом препятствий). Сопла имеют объёмное анимированное пламя, которое не зависит от дальности частиц. Клиент сглаживает серверные координаты в течение трёх тиков. Пока нет ходьбы внутри, разделения ступеней, физики столкновений, топлива, невесомости и планет. Полёт условный, препятствия не проверяются. Компиляция и запуск игры ещё требуют подтверждения.

## Лунная миссия
После достижения Y=10000 ракета с пассажиром переходит в космическое измерение на X=0.5. Далее она физически летит до X=6000.5, Y=180 и плавно опускается на Y=101. Луна — небольшой блоковый шар диаметром 96 блоков с полой корой и посадочной площадкой. Генерация ограничена по работе на тик. В открытом космосе гравитация сущностей нулевая; около Луны плавно возрастает до 0.165 земной. Направление вниз стандартное, радиальной гравитации, скафандров и кислорода пока нет. После посадки Shift высаживает рядом на площадку. Для возвращения /rocket return. Не сходите с ракеты в открытом космосе. Смена измерения при выходе с Земли остаётся необходимой. Скорость перелёта до 100 блоков/с.

## Обновление 0.4.0 — Lunar Mission
Автопилот: ожидание на орбите, разгон, инерционный участок, разворот, торможение, ожидание готовности Луны, выравнивание, спуск и мягкая посадка. Траектория дугой (до 36 блоков выше прежней), максимальная скорость перелёта 100 бл/с; пламя выключается на инерционном участке. Модель и обзорное место поворачиваются вокруг середины корпуса; коллизия пока вертикальная. /rocket status показывает этап, прогресс горизонтального пути, дистанцию, скорость и высоту над площадкой. Миссия сохраняется в NBT; после перезагрузки продолжится с пассажиром. Если пассажир вышел, движение приостанавливается; повторная посадка или /rocket launch рядом возобновляет полёт. /rocket return остаётся аварийным возвратом с телепортацией. Траектория кинематическая, не полноценная орбитальная механика. Смена измерения Земля–космос сохраняется. Для проверки используйте копию мира.
